# DropEase 🚚

**Delivery Route Optimization Made Easy**

A modern, responsive landing page for DropEase - an intelligent route optimization platform designed specifically for delivery drivers and logistics companies.

![DropEase Preview](https://images.pexels.com/photos/4391470/pexels-photo-4391470.jpeg?auto=compress&cs=tinysrgb&w=1200&h=600&fit=crop)

## 🌟 Features

### Landing Page Highlights
- **Modern Design**: Clean, professional interface with smooth animations
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, smooth scrolling, and micro-interactions
- **Contact Form**: Functional contact form with validation and notifications
- **Performance Optimized**: Fast loading times and smooth user experience

### DropEase Platform Features Showcased
- Smart Route Optimization with AI-powered algorithms
- Real-time GPS Tracking and live updates
- Digital Proof of Delivery with signatures and photos
- Driver Mobile App with offline capabilities
- Analytics Dashboard for performance insights
- Customer Notifications via SMS and email

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Basic understanding of HTML, CSS, and JavaScript

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/dropease.git
   cd dropease
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your preferred browser
   open index.html
   # or
   python -m http.server 8000  # For local server
   ```

3. **For development**
   ```bash
   # Use any local server like Live Server in VS Code
   # or Python's built-in server
   python3 -m http.server 8000
   ```

## 🔧 Customization

### Updating Colors
Modify the CSS custom properties in `styles.css`:

```css
:root {
    --primary-color: #your-color;
    --secondary-color: #your-color;
    /* ... other colors */
}
```

### Adding New Sections
1. Add HTML structure in `index.html`
2. Style in `styles.css`
3. Add JavaScript functionality in `script.js` if needed

### Modifying Content
- Update text content directly in `index.html`
- Replace placeholder images with your own
- Modify pricing plans and features as needed
